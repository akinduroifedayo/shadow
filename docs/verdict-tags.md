# Trial-aware verdict tags

Trial records store `intent`, either `switch` or `compare`. The shared record parser assigns `switch` when an older saved record has no intent. `/shadow try` and the Desktop start card's Start button create switch candidates. `/shadow compare`, `hermes shadow compare`, and the Desktop start card's secondary Compare button start comparisons. Both Desktop buttons submit the same consent card through the start RPC. A second look retains the original intent.

The tag registry in `shadow/trial/presentation.py` maps intent, the saved verdict outcome, and cost comparison to keyed copy. It leaves judging and stored confidence intervals unchanged. The saved `too_close` outcome gets the extra-turn hint only before a second look and when the judge panel remains eligible. A `holds_up` result remains a quality tie under the existing judging rule, even when its confidence interval includes even.

Savings use a strictly lower stored cost per turn, including savings below 1%. Equal costs do not count as savings. The stored `saved_pct` is floored and does not decide the tag. For a comparison tie, either model matched for less when its stored cost per turn is strictly lower. The `small_premium` band requires a stored `more_pct` of at most 1. The stored premium percentage is rounded up. Larger premiums use the higher-cost band.

Unknown or estimated prices cannot support a savings claim. Both models on a plan, or only the trial model on a plan, use the same-or-lower cost band when costs are known. Only the current model on a plan uses the unknown band because moving to paid use cannot support a same-or-lower cost claim.

| Intent | Saved outcome | Tag |
| --- | --- | --- |
| switch | better | Safe to switch at the same or lower recorded cost, or a small premium within the same cost band. The trial model came out ahead at higher or unknown cost. |
| switch | holds_up | Switch saves money at any lower recorded cost. Safe to switch at equal cost, within a plan cost band, or at a small premium. Even match at higher or unknown cost. |
| switch | worse | Stay on your current model. |
| compare | better | The trial model came out ahead. |
| compare | worse | The current model came out ahead. |
| compare | holds_up | The cheaper model matched it for less at any lower recorded cost. Even match otherwise. |
| either | too_close | Too close to call. Run more turns to separate them appears only when another look is available. |
| either | not_enough | Too close to call, with the existing insufficient-evidence reason and actions. No extra-turn hint. |

Compare reason lines name both models without referring to either as the incumbent. They describe which model led, a quality tie, or an unresolved comparison. The confidence receipt explains the tie rule and the direction of the lean without using the former verdict labels.

Comparison intent comes from a separate action. A quality win at higher or unknown cost names the trial model as ahead, and a quality tie uses Even match. Premiums of at most 1% use Safe to switch within the same cost band. Plan list values never support a savings claim, and a current-plan-only user never gets Safe to switch.
